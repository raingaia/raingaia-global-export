The shared discipline

The same four principles show up in every RAINGAIA product, adapted to what each domain's sensors actually produce. This is what "one evidence engine" means in practice.

01
Source-relative baseline
Every source — a network host, a structural sensor point, a physiological channel — gets its own learned baseline instead of one global "normal." A warmup period establishes what normal looks like specifically for that source before anything is scored against it.
02
Multi-channel evidence fusion
Independent signal channels are tracked and decayed separately, then fused into one composite assessment — cross-checking multiple views of the same underlying event instead of trusting a single signal in isolation.
03
Threshold-free, probabilistic decisions
Verdicts come from a source-relative probability distribution over possible states, not a fixed magic-number threshold — and the same input always produces the same output, which is what makes a decision auditable at all.
04
Tamper-evident audit trail
Every decision is written to a cryptographically chained audit log — each entry linked to the one before it, so a retroactively altered record breaks the chain. Evidence you can hand to someone else, not just a dashboard.
